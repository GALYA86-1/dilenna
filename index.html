🚀 0. АКТУАЛІЗАЦІЯ ЗНАНИХ ФАКТІВ (ПРАВДА ЧИ БРЕХНЯ?)

Давайте повторимо базові поняття перед вивченням ділення! Дайте відповідь на 5 запитань:

1. Дію, за допомогою якої за добутком та одним з множників знаходять інший множник, називають діленням.
2. На нуль ділити можна.
3. При діленні будь-якого числа (не рівного нулю) на самого себе отримуємо одиницю.
4. Щоб знайти невідоме ділене, треба частку помножити на дільник.
5. При діленні числа на одиницю число не змінюється.

🔥 1. ВИВЧЕННЯ НОВОГО МАТЕРІАЛУ ТА ПРАКТИКА

📌 ГОЛОВНІ ПРАВИЛА ТА ПОНЯТТЯ ДІЛЕННЯ:

  • Основна рівність: a : b = c (де a — ділене, b — дільник, c — частка).
  • ⚠️ УВАГА! На нуль ділити категорично не можна! (b ≠ 0).
  • ⭐ Властивості одиниці та нуля:
    • a : a = 1 (при a ≠ 0)
    • a : 1 = a
    • 0 : a = 0 (при a ≠ 0)
  • 💡 Ділення на розрядну одиницю (10, 100, 1000 тощо): щоб поділити число на 10, 100 чи 1000, достатньо відкинути справа стільки нулів, скільки їх у розрядній одиниці.
